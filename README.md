　「Better Bookmark Sidepanel」は、ブックマークや、「現在開いているタブ」、「今日閉じたタブ」をサイドパネルに表示するChromeの拡張機能です。

【Better Bookmark Sidepanelの特徴】
　「Better Bookmark Sidepanel」は、ブックマークだけでなく、「現在開いているタブ」や「今日閉じたタブ」のリストをサイドパネルに表示することができます。
　ブックマークやフォルダの位置を自由に入れ替えることができます。
　複数のブックマークやフォルダを一括で選択して削除することができます。

【Better Bookmark Sidepanelのインストール】
(1) Chromeの拡張機能の「デベロッパーモード」をONに設定します。
(2) 「パッケージ化されていない拡張機能を読み込む」をクリックします。
(3) この拡張機能が保存されているフォルダを選択します。

【Better Bookmark Sidepanelのオプション】
(1) 「タブを開く位置」：新たなタブを開く位置を、「最後に開く」、または、「アクティブタブの後に開く」に設定します。
(2) 「アクティブタブの動作」：新たなタブを開いたときに、「現在のタブをアクティブのままにする」、または、「新しいタブをアクティブにする」に設定します。
(3) 「削除時の確認」：ブックマークやフォルダを削除するときに、「確認画面を表示する（デフォルト）」、または、「確認せずに削除する」に設定します。
(4) 「外観」：「ブックマークの表示文字サイズ」、および、「行間隔」を設定します。

【Better Bookmark Sidepanelの使い方１】
　この拡張機能のアイコンをクリックするか、もしくは、ショートカットキー（Mac：command＋B、Windows：CTRL+B）を押すと、「Better Bookmark Sidepanel」のサイドパネルが表示されます。デフォルトでは、ブックマークのリストが表示されます。
　もう一度、この拡張機能のアイコンをクリックするか、もしくは、ショートカットキーを押すと、「Better Bookmark Sidepanel」のサイドパネルが表示されなくなります。

【Better Bookmark Sidepanelの使い方２】
　ブックマーク
　ブックマークをクリックすると、そのブックマークのウェブページが、現在開いているタブに表示されます。Macでは、ブックマークをcommand+クリック、Windowsでは、ブックマークをCTRL+クリックすると、そのブックマークが、新たなタブに表示されます。
　ブックマークを右クリックすると、サブメニューの「名前の変更」、および、「削除」が表示されます。「名前の変更」をクリックすると、ブックマークやフォルダの名前を変更でき、「削除」をクリックすると、ブックマークやフォルダを削除できます。
　フォルダを右クリックすると、サブメニューの「フォルダ内の全てのブックマークを開く」、「名前の変更」、「削除」が表示されます。「フォルダ内の全てのブックマークを開く」をクリックすると、フォルダ内の全てのブックマークが新たなタブに表示されます。「名前の変更」、「削除」は既に説明した通りです。
　ブックマークやフォルダの右端のチェックボックスをクリックし、サイドパネルの上部右側の右から２つ目の「削除」ボタンをクリックすると、チェックボックスがオンのブックマークやフォルダを一括で削除できます。
　サイドパネルの上部右側の左端の「新規フォルダ」ボタンをクリックすると、最後に選択した（開いた、または、閉じた）フォルダの直下に新規フォルダが作成されます。
　サイドパネルの上部右側の左から２つ目の「検索」ボタンをクリックすると、検索窓が表示され、ブックマークやフォルダを検索できます。

【Better Bookmark Sidepanelの使い方３】
　現在開いているタブ
　サイドパネルの上部左側の中央の「現在開いているタブ」ボタンをクリックすると、現在開いているタブのリストが表示されます。
　現在表示中のタブがハイライト表示されます。
　他のタブをクリックすると、そのタブがハイライト表示され、現在表示中のタブから、クリックされた他のタブに切り替えて表示されます。

【Better Bookmark Sidepanelの使い方４】
　今日閉じたタブ
　サイドパネルの上部左側の右端の「今日閉じたタブ」ボタンをクリックすると、今日閉じたタブのリストが表示されます。
　タブをクリックすると、クリックされたタブが新たなタブに表示されます。
　サイドパネルの上部右側の左端の「今日の履歴をクリア」ボタンをクリックすると、今日閉じたタブのリストがクリアされます。

【Better Bookmark Sidepanelの使い方５】
　ブックマーク
　「現在開いているタブ」のリストや「今日閉じたタブ」のリストが表示されているときに、サイドパネルの上部左側の左端の「ブックマーク」ボタンをクリックすると、ブックマークのリストが表示されます。

【まとめ】
　「Better Bookmark Sidepanel」を使えば、ブックマークのリストを表示し、ブックマークやフォルダの位置を自由に入れ替えることができます。また、「現在開いているタブ」のリストや、「今日閉じたタブ」のリストを表示できます。
